Diferencia entre Function y Arrow Function

Las funciones tradicionales y las Arrow Functions tienen diferencias importantes en sintaxis, manejo de this, uso como constructores y acceso al objeto arguments. Aquí te mostramos un resumen ampliado:

Comparación detallada

Aspecto Function tradicional Arrow Function
Sintaxis function nombre(){...} () => {...}
Manejo de this Dinámico, depende de la invocación Léxico, hereda del contexto
Uso como constructor Sí, con new No
Objeto arguments Disponible No disponible, se usa ...args
Hoisting Se puede invocar antes de declararse No se eleva, debe declararse antes
Uso típico Métodos, constructores, funciones complejas Callbacks, funciones cortas, programación funcional

Ejemplo comparativo

      // Función tradicional
      function saludar(nombre) {
        return "Hola " + nombre;
      }

      // Arrow Function
      const saludar = (nombre) => `Hola ${nombre}`;
